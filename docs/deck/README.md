# Use-case deck

`arabic-video-search-use-cases.pptx` shows how the Arabic AI Video Search PoC would be used: a suspect, a left bag and a lost child.
It is generated by `build_deck.py` (python-pptx, MIT licence); edit the script, not the .pptx.

Rebuild it from the repository root with `uv run docs/deck/build_deck.py`.

The deck uses the Aptos and Dubai fonts, which ship with Microsoft 365; Dubai renders the Arabic text.
Each slide's speaker notes name the source section of the PoC technical plan and its upstream links.
